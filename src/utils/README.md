# Utils

## Purpose

The `utils` directory contains small, reusable helper functions.

These functions should be framework-independent whenever possible.

---

## What belongs here

- formatPrice
- formatBytes
- generateId
- debounce

---

## What does NOT belong here

- React Components
- API Clients
- Business Logic

---

## Principles

- Functions should be pure whenever possible.
- Keep utilities small.
- Avoid dependencies on React.

---

## Examples

```
formatPrice.ts
capitalize.ts
generateId.ts
```
