# UI

## Purpose

The `ui` directory contains reusable user interface components.

These components are designed to be shared across the entire project.

---

## What belongs here

- Button
- Input
- Card
- Badge
- Modal
- Tooltip
- Spinner
- Container

---

## What does NOT belong here

- Business logic
- API requests
- Feature-specific behavior
- Page sections

---

## Principles

- Components should be reusable.
- Components should remain independent.
- UI should not know business rules.
- Keep components simple and composable.
