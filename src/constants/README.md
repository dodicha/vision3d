# Constants

## Purpose

The `constants` directory contains values that should remain unchanged throughout the application.

---

## What belongs here

- Routes
- Limits
- Default values
- Configuration constants

---

## What does NOT belong here

- Runtime calculations
- Functions
- Business logic

---

## Principles

- Constants should never change during execution.
- Use descriptive names.
- Avoid magic numbers.

---

## Examples

```
routes.ts
viewer.ts
limits.ts
```
