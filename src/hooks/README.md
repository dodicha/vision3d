# Hooks

## Purpose

The `hooks` directory contains reusable custom React Hooks.

Hooks encapsulate reusable behavior, not UI.

---

## What belongs here

- useTheme
- useViewer
- useUpload
- useAnimation

---

## What does NOT belong here

- Components
- Pages
- API clients

---

## Principles

- Hooks should solve one problem.
- Prefer composition over complexity.
- Keep hooks reusable.

---

## Examples

```
useTheme.ts
useUpload.ts
useViewer.ts
```
