# Types

## Purpose

The `types` directory contains shared TypeScript types and interfaces.

---

## What belongs here

- Interfaces
- Type aliases
- Shared models

---

## What does NOT belong here

- Functions
- Components
- Business logic

---

## Principles

- Types should describe the project language.
- Keep them reusable.
- Avoid duplication.

---

## Examples

```
Product.ts
Viewer.ts
User.ts
```
